# GPT reactive transport review pack

This directory contains a derived literature pack for analyzing reactive-transport papers and reviewing code for a PHREEQC-coupled reproduction workflow.

## Files

- `merged_pdfs/`: 7 merged PDF volumes, each with bookmarks for the original papers or SI.
- `PDF_CONTENT_GUIDE.md`: Chinese guide describing each merged PDF and every included source paper/SI.
- `source_pdf_index.csv`: Machine-readable source index.
- `manifest.json`: Build metadata, paths, grouping, page counts, token estimates, and environment notes.
- `GPT_PROJECT_INSTRUCTIONS.md`: Recommended GPT project instruction file.
