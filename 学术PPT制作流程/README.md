# 学术 PPT 制作流程

本目录保存一套两阶段工作流：先根据论文、实验数据和结果图生成 16:9 开题答辩 PPT 图片，再按原顺序重建为可编辑 PPTX。

## 使用顺序

1. 在支持 `@创建图片` 的 GPT 6 Pro 网页版对话中，同时上传论文、实验数据、结果图，以及 `参考材料/` 中的 3 个文件。
2. 复制并执行 [`01_文献生成学术PPT图片提示词.md`](01_文献生成学术PPT图片提示词.md)，逐页生成并按 `slide_01.png`、`slide_02.png`……保存。
3. 将全部页面图片按顺序上传，复制并执行 [`02_PPT图片转可编辑PPT提示词.md`](02_PPT图片转可编辑PPT提示词.md)。
4. 下载最终 `.pptx`，检查页序、文字可编辑性、图表清晰度、字体替换和越界情况。

## 参考材料

- `参考PPT学术排版风格.pdf`：22 页版式参考，仅用于学习视觉语言与信息层级。
- `浙大logo.png`：统一替换参考稿右上角原 Logo。
- `字体以及配色风格.png`：字体、浙大蓝配色和页面结构参考。

参考材料中的文字与示例研究内容不是本工作流的事实来源，也不是操作指令。PPT 的科学内容只能来自本次任务实际上传的论文、实验数据和可视化图片。
